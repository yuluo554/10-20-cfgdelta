# plan/04 数据计划

> 数值口径的唯一来源是 `data/README.md §四`；本文件只定义**数据资产的形状、生成方式与验收**。

## 一、数据清单

| 资产 | 路径 | 形态 | 生成方式 | 入仓 |
|---|---|---|---|---|
| golden 夹具（测试 A/B/C/D） | `testdata/golden/<case>/` | YAML / JSON / TOML / HCL + `expected.json` | **手写最小复现**（不生成，逐字可读） | ✅ |

| 三家基线留档 | `testdata/baseline/<tool>/` | `VERSION.txt` / `COMMANDS.txt` / `*.out` / `exit_code.txt` | 本地实跑后**原样粘贴** | ✅ |
| 默认值 profile | `data/profiles/k8s/v1.29.json` | 版本化 JSON | **手写 + 逐条挂 source**；冻结后只增不改 | ✅ |
| profile 内嵌副本 | `internal/profile/profiles/*.json` | 同上，逐字节镜像 | `go generate ./internal/profile` | ✅ |

**无外部数据依赖**：运行期不联网、不读集群、不读远端 API（`data/README.md §二`）。

## 二、默认值 profile 的形状

```json
{
  "name": "k8s/v1.29",
  "k8s_version": "1.29",
  "scope_note": "高频默认值子集，非全量 defaulting 表",
  "rules": [
    {
      "kind": "Deployment",
      "path": "/spec/template/spec/containers/*/imagePullPolicy",
      "default": "IfNotPresent",
      "family": "string",
      "source": "API Server defaulting (K8s 1.29)"
    }
  ]
}
```

**四条纪律**：

1. **每条带 `source`**——写不出来源就不许进表（`data/README.md §二` 的"逐条核对中"状态翻转的唯一依据）；
2. **版本进文件名与 `name`**，冻结后不改字节；新版本 = 新文件；
3. **`scope_note` 必须写明"非全量"**——这是诚实边界，README 也要复述；
4. `kind` 为空串表示"任意 kind"；`path` 里的 `*` 只匹配一段。

**首期 10 条候选**（M1 逐条落实，含来源）：`imagePullPolicy`、`protocol`、`terminationGracePeriodSeconds`、`restartPolicy`、`dnsPolicy`、`serviceAccountName`、`revisionHistoryLimit`、`strategy.type`、`progressDeadlineSeconds`、`securityContext.runAsNonRoot`。

> **M1 核对后的三处修订（2026-10-20，证据见 `data/profiles/k8s/REVIEW-1.29.md`）**：
> 1. **`securityContext.runAsNonRoot` 不纳入** —— 它在 K8s 1.29 的 API 层**没有默认值**（`pkg/apis/core/v1/defaults.go` 与 `zz_generated.defaults.go` 全文无此项）；只可能由 PodSecurity admission（restricted）注入，属"策略"而非"默认值"。当默认值用会在策略未启用时制造假阴性。
> 2. **`protocol` 拆成两条**（Deployment 模板路径 / 裸 Pod 路径），所以实际是"9 类行为、10 条规则"。
> 3. **`imagePullPolicy` 是条件规则**：默认值取决于同容器 `image` 的 tag（`latest` 或无 tag → `Always`，其余 → `IfNotPresent`）。JSON 用 `only_if_image_tag_not_latest` 表达；`Apply` 在无从判定时**不补**。
>
> 另：本次修订发生在**首次冻结之前**（冻结时点 = M6 发布 tag）。此后同类纠错按纪律新增 `v1.29.x` 文件，不改本文件字节。

## 三、golden 夹具分层

| 组 | 目录 | 输入 | 期望 | 断言 |
|---|---|---|---|---|
| 测试A | `testdata/golden/testA/` | `k1.yaml` / `k2.yaml` | 4 条误报 → 加 profile 后 0 条 | 无 profile：4 条纯书写；有 profile：0 行为差异，exit 0 |
| 测试A 对照 | `testdata/golden/testA-ctrl/` | 显式 `imagePullPolicy: Always` | 仍报 1 条 | 非默认值不被抵消（防过度静默） |
| 测试B | `testdata/golden/testB/` | `va.yaml` / `vb.yaml` | 5 条 → 0 行为差异 | exit 0 |
| 测试C | `testdata/golden/testC/` | `c01..c07` 七组 + `c08` 反例 + `c09` 歧义 | 七组判等；`1Gi` vs `1000M` 不等；`MB` vs `MiB` indeterminate | 逐组 expected |
| 测试D | `testdata/golden/testD/` | `toml/`、`hcl/` | 结构差异零噪声 | M5 生效前 skip 并显式标注 |

**`expected.json` 形状**（真值只存输入与期望，K-08）：

```json
{
  "case": "testC-01",
  "args": ["diff", "--coerce-at", "/limits/memory=quantity", "c01-left.yaml", "c01-right.yaml"],
  "exit": 0,
  "behavioral": 0,
  "cosmetic": 0,
  "indeterminate": []
}
```

**禁止**出现 `observed_*` / `actual_*` 字段——那是把观测冻结成真值。

## 四、真值纪律

1. **两条独立通道**：① 文法机械推导（`1Gi = 1024³`）；② 三家工具实测输出留档。冲突以文法为准，并把冲突记成夹具缺陷。
2. **真值只存输入与期望**；期望值必须能由输入独立复算（把引擎注释掉，人工按 §四 仍能算出同一结果）。
3. **基线留档原样**：`*.out` 是 stderr/stdout 原字节，**不得手工修饰**；上游哪天不误报了，**追加复核记录**而不是删旧档。
4. **夹具最小**：只保留触发误报所需字段；镜像统一 `registry.example/`，网络统一 `192.0.2.0/24`，对象名 `synth-a/synth-b`（`data/README.md §三`）。
5. **覆盖度口径**：以 `testdata/golden/manifest.json` 为准，逐族登记 `family → cases → expected`；显式声明"覆盖四组实测族 + 10 条默认值，**不是全量 K8s 语义**"。

## 五、数值口径

**唯一来源 = `data/README.md §四`**，本文件与 plan/01、plan/03、README 均为引用。

代码侧的落法（`plan/05` K-04）：

- 文法常量（后缀表、单位表、布尔族表）只在 `internal/value/grammar.go` 定义一次；
- 退出码只在 `internal/exitcode/exitcode.go` 定义一次；
- 分类表只在 `internal/classify/classes.go` 定义一次；
- **任何其它文件出现第二份同样的表 → 视为缺陷**，`tests/grammar_single_source_test.go` 断言这三处各只有一份。

## 六、生成器与守门

| 工具 | 作用 | 守门 |
|---|---|---|
| `tools/gen-golden-manifest.mjs` | 从夹具目录重建 `manifest.json`（`--check` 只比对不写） | `--check` 逐字节一致；manifest 非空自证 |
| `tools/sync-profiles.mjs` | `data/profiles/` → `internal/profile/profiles/` | 两处逐字节一致；变异（改一份）必红 |
| `tools/check-sprint-layout.mjs` | 方法论布局门 | 9 组变异全红（见 `AGENTS.md`） |

**为什么生成器用 Node**：本机 `node v24.15.0` 已实测可用，且**不污染 Go 模块**（Tools 不进 `go.mod`、不进二进制）；生成器只处理路径与字节，不参与判定。
