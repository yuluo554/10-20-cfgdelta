# plan/03 模块详设

> 数值口径**一律引用 `data/README.md §四`**，本文件不复制文法与表格。
> 本文件回答"每个模块的输入/输出/失败态是什么"，以及 CLI 契约总表。

## 一、内部文档树（`internal/doc`）

### 1.1 三态与来源保留

| 概念 | 字段 | 为什么必须有 |
|---|---|---|
| 解析后 tag | `Node.Tag` | 区分 `1`（`!!int`）与 `"1"`（`!!str`）——类型族血缘 |
| 书写风格 | `Node.Style` | `yes`（plain）归一为 bool；`"yes"`（quoted）保持字符串 |
| 原文 | `Node.Raw` | `1Gi` / `1e3` / `0.5` 的精确文本是归一引擎的唯一输入 |
| 位置 | `Node.Line/Col` | 解析错误与 `keyed:` 重复键必须给定位 |

### 1.2 解析契约

| 输入形态 | 处理 | 失败态 |
|---|---|---|
| 单文档 YAML | 一个根节点 | `ParseError{file,line,col,msg}` → exit 3 |
| 多文档 YAML（`---`） | 根为 `Sequence`，每文档一项 | 同上 |
| JSON | `Decoder.UseNumber()`，`Raw` 保留数字原文 | 同上 |
| 空文件 | 根为 `null` 标量 | **不是错误**（§4.5 显式 null 与缺失不同） |
| 注释 | 解析期丢弃，**不参与比较** | 输出头标注 `comments: not compared` |
| 缩进 / 引号风格 | 不影响 `Raw` 的语义归一（`Style` 只用于 bool 判定） | — |

**不做的事**：多文档 YAML 之外的锚点/别名不做展开（`yaml.v3` 会给 `Alias` 节点，M2 处理为 `indeterminate(unevaluated_expression)`）；不做表达式求值（HCL 在 M5）。

## 二、M1 normalize（`internal/value`）

| 函数 | 输入 | 输出 | 失败态 |
|---|---|---|---|
| `Normalize(n *doc.Node, fam Family) (Canonical, error)` | 标量节点 + 族声明 | 规范值 | `ErrIndeterminate{Reason}` / `ErrParse` |
| `Compare(a, b Canonical) (Equal, Indeterminate, NotEqual)` | 两个规范值 | 三态 | 族不同 → `indeterminate(unknown_family)`（除非显式强转） |
| `inferFamily(n *doc.Node) Family` | 标量节点 | 默认族或 `unknown` | — |

**默认族推断规则（只三族，K-06）**：

1. `Tag=!!bool` 或 `Style==plain` 且落布尔族表 → `bool`；
2. `Raw` 命中 quantity 文法（后缀或纯数字且**带明确的 K8s 上下文路径**）→ `quantity`；
3. `Raw` 命中 duration 文法（含 `ns/us/µs/ms/s/m/h` 任一单位）→ `duration`；
4. `Raw` 命中十进制文法 → `decimal`；
5. 其余 → `string`（**默认按原样比较，不升级为 indeterminate**）；
6. `--strict` 下第 5 类且两侧书写不同 → `indeterminate(unknown_family)`。

> 路径上下文判定：`*resources.limits.*` / `*resources.requests.*` 下才默认 quantity；其余位置的裸数字按 `decimal`。这条写在 `internal/value/family.go` 的**唯一一处**，golden 覆盖它。

**规范值字符串（冻结）**：`quantity|duration|decimal` 一律输出 `family:value` 形式，例如 `quantity:1073741824/1`、`duration:90000000000`、`decimal:3/2`。排序与序列化都只认这个字符串（K-04）。

## 三、M2 diff（`internal/diff`）

| 模式 | 语义 | 重复/歧义 |
|---|---|---|
| `ordered`（默认） | 按位置逐项比较，长度差成 Added/Removed | — |
| `set` | 元素规范化后按字节序排序再比对 | 重复元素 → `indeterminate(duplicate_in_set)` |
| `keyed:<field>` | 按字段值对齐 | **键必须唯一 → exit 3 + 重复键路径** |

**路径格式**：JSON Pointer（`/spec/containers/0/image`），键内 `/` 与 `~` 按 RFC 6901 转义。

**输出头（文本模式）**：

```
cfgdelta v0.1.0 · profile k8s/v1.29 (hits: 2) · seq-mode ordered · comments: not compared
```

未命中 profile 时：`profile k8s/v1.29 (hits: 0) · degraded: structural-only`。

## 四、M3 profile（`internal/profile`）

| 项 | 契约 |
|---|---|
| 数据源 | `data/profiles/<name>.json`，构建期同步进 `internal/profile/profiles/` 内嵌 |
| 名称格式 | `<vendor>/v<major>.<minor>`，未知 → exit 3 + 可用列表 |
| 规则字段 | `kind` / `path`（`*` 通配一段）/ `default` / `family` / `source` |
| 施加顺序 | 外层先于内层、父先于子、同层按路径字节序（§4.11） |
| 抵消 | 双侧施加后相同默认值自然相等 → 不产生条目 |
| 降级 | 未命中任何规则 → 头部 `degraded: structural-only`，**不静默** |

## 五、M4 classify + gate（`internal/classify`）

| 类 | 常量 | 判定线索 |
|---|---|---|
| 资源·收缩 | `ResourceShrink` | `limits/requests` 同族归一后变小；`replicas` 变小 |
| 部署·收缩 | `DeployShrink` | `maxUnavailable` 变大 / `minReadySeconds` 变大 |
| 镜像·变更 | `ImageChange`（子类 `major/minor/patch/non-semver`） | `image` 引用变化，semver 比较 |
| 接口·暴露 | `Exposure` | Service `ports/type/selector`、Ingress 路由 |
| 配置·新增·移除 | `ConfigChange` | `env`、ConfigMap/Secret key 的增删 |
| 纯书写 | `Cosmetic` | 归一后相同或仅呈现差异 → **只计数** |

**分类不确定** → 归 `ConfigChange` 并标 `class_guess: true`；**禁止**归 `Cosmetic`（§4.13）。

**gate**：`gate --fail-on <逗号分隔类>`，只让列出的类触发 exit 1；未列出的行为差异照常输出。`indeterminate` 恒 exit 2（除非 `--allow-indeterminate`）。

## 六、CLI 契约总表

| 子命令 | 必选参数 | 可选参数 | 退出码 |
|---|---|---|---|
| `normalize` | `--at <path> --family <fam> <file>` | `--json` | 0 / 2 / 3 |
| `diff` | `<left> <right>` | `--profile` `--seq-mode` `--strict` `--coerce-at` `--classify` `--json` `--dump-normalized` `--allow-indeterminate` | 0 / 1 / 2 / 3 |
| `classify` | `<left> <right>` | 同 `diff` | 0 / 1 / 2 / 3 |
| `gate` | `--fail-on <classes>` `<left> <right>` | 同 `diff` | 0 / 1 / 2 / 3 |
| `selftest` | — | `--verbose` | 0 / 1 |

**全局**：`--version`（打印 `cfgdelta <ver>`）、`--help`。未知子命令/缺必选参数 → **exit 3**（不用 argparse 式 exit 2，本项目 `3` 是"用法错误"的唯一码；K-07）。

**`selftest`** 跑 `testdata/golden/` 的 A/B/C/D 四组 + 退出码参数化断言，一条命令零外部依赖。
