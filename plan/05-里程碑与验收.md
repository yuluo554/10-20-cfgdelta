## 三、K 编号（既定口径清单，动了会打挂测试）

| 编号 | 口径 | 落点 |
|---|---|---|
| K-01 | **禁止浮点参与相等判定**：比较路径只允许 `*big.Rat` / `int64` 纳秒 / 枚举 | `internal/value` + `tests/float_ban_test.go` |
| K-02 | 输出确定性：键按字节序、不读时钟、不读环境变量、双跑逐字节一致 | `internal/diff` + `selftest` |
| K-03 | 构建固定 `CGO_ENABLED=0 -trimpath -ldflags "-s -w -X main.version"`，版本单一来源 = `VERSION` | `Makefile` / CI / `main.go` |
| K-04 | 规范值字符串形态冻结：`family:value`；排序与序列化只认它 | `internal/value/canonical.go` |
| K-05 | `keyed:` 重复键 = **exit 3 + 路径**，禁止取首 | `internal/diff` |
| K-06 | 默认族只推断三族（quantity/duration/decimal）＋bool；其余按 string 原样比较 | `internal/value/family.go` |
| K-07 | 用法错误统一 exit 3（含未知子命令/缺参），**不使用 2** | `internal/cli` |
| K-08 | `expected.json` 只存输入与期望，**禁止 `observed_*`** | `testdata/golden` |
| K-09 | 默认值表外置版本化 JSON，`scope_note` 必写"非全量" | `data/profiles` |
| K-10 | `indeterminate` 必带理由码，优先级 2 > 1 | `internal/exitcode` |
